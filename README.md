# OpenBao Operator documentation continuity

This user site preserves the documentation previously published by `dc-tec/openbao-operator`.
The operator pages live under `openbao-operator/`. GitHub Pages publishes the `main` branch at `/`.

The frozen source is the operator repository's `gh-pages` commit `719664fb17b3efe1af8161f1425ec0727fc3e446`.
Every published file is preserved byte-for-byte, including historical edge and nightly manifests,
metadata, checksums, and signature bundles. These channel files are frozen historical artifacts.

After the KubeBao documentation site is available at `https://docs.kubebao.org/` with valid HTTPS,
known HTML routes can become browser redirects. Preserve machine-readable files at their original paths.
Do not add a custom domain to this user site or recreate the old operator repository name.
